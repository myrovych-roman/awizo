# Система реєстрації в'їзду "Авізо"

Проста локальна система реєстрації в'їзду транспорту на охоронювану територію.

## Встановлення

1.  Встановіть Python 3.11.
2.  Встановіть залежності:
    ```bash
    pip install Flask
    ```

## Запуск

1.  Перейдіть до каталогу `awizo`:
    ```bash
    cd awizo
    ```
2.  Запустіть додаток:
    ```bash
    python app.py
    ```
3.  Відкрийте у браузері адресу `http://127.0.0.1:5000`.
